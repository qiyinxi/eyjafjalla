# 影像 · 三个夏天（+ 汐斯塔番外）—— MV 创作圣经（开发文档）

用户的要求（原话）：「帮我为这三首歌生成 mv 保持风格，创建人物，自创场景，编故事，呈现就交给你自己；并将其合理的融入到网页中」；
补充：「人物场景故事跟随网页主题吧还是，都是同一主题的」「有的是有官方 mv 的，你也可以参考」；
之后又给了两首：「这两个可以在做完这三个你觉得没啥问题了你再做」。
总体要求：不计成本、尽最大努力；画面好看、故事动人、处处在动；性能是硬约束（用户曾因显卡风扇狂转而投诉）。

所以：五支 MV 都讲**艾雅法拉（阿黛尔·瑙曼）**的世界，同一个主题。前三支是三部曲——**她的三个夏天**；
后两支是**汐斯塔番外**（同一天的两个视角），它们在时间上正好接进第二部的那个夜晚。
全部画面是**本页原创**的实时渲染动画（Canvas 2D），随音乐的拍点 / 段落切镜头。它是同人作品，片尾要注明“非官方”。

## 0. 红线（必须遵守）

- **绝不显示、转写、改写歌词**，也不要去抓取 / 阅读 lyric 文件。画面上的文字只能是我们自己写的旁白、标题、片尾字幕。
- 不要把网络上的图片 / 视频下载进项目。MV 里的一切（场景、人物、特效）都用代码画出来；官方资料只作“参考风格”。
- 不上传任何东西到任何地方。只在 `D:\claude_projects\Eyjafjalla` 里工作。
- 设定遵守 PRTS 上的正史；**原创的细节可以有，但不能和正史冲突**（例如：父母是在乌纳火山的考察中遇难的；小黑羊是母亲送的；多利是羊之兽主；纯烬时期她穿着母亲的火山防护外套；她在乌纳火山山顶埋下一块小石头，两个花环在无风的山顶飞走）。
- 不要写“她是唯一……”之类无法核实的说法。
- 画面要“处处在动”，但**不用 shadowBlur / CSS filter / 大面积 feGaussianBlur**；发光一律用引擎的柔光精灵（`s.glow`）。

## 2. 故事总纲：她的三个夏天

一件贯穿三部的小物件：**一块火山浮石**（会浮在水面、投进水里嗞嗞作响——纯烬的信物）。
- I：爸爸出发前答应“从乌纳火山带一块石头回来”。
- II：梦里，两只小黑羊把一块石头推到她手心。
- III：她自己把一块小石头埋在乌纳火山山顶。

另外几条贯穿线：**磁带 / 录音**（I 里她第一次录下家里的声音 → III 里“想要留住的声音”那盘磁带）；**母亲的外套**（I 里挂在门口、II 里她穿上、III 里穿着登顶）；**小黑羊 / 粉色小羊**；**信**（I 里母亲把一封信悄悄夹进文件——正史里她整理遗物时找到它；III 里她在半山腰重读）。

### I · 夏天之前（Before Summer）
莱塔尼亚，威廉大学所在的学院城。**六月的某一天**，平凡得不能再平凡。十来岁的阿黛尔已经在大学里旁听课程（正史：她很早就在莱塔尼亚的名校留下了名字）。明天，爸爸妈妈就要出发去乌纳火山做实地考察——那是他们的最后一个夏天，但片中**绝不明说**，只在最后留一个极轻的暗示。
基调：明亮、调皮、怀旧，午后的暖光；结尾是黎明的离别，温柔而不悲情。

### II · 雾中之忆（Misty Memory, Night）
多年后，汐斯塔的夏天。纯烬时期的她在火山博物馆整理标本到深夜，趴在桌上睡着。角落的货箱一歪，一群粉色小羊（多利的化身）滚了出来，汽水瓶打翻、气泡冒成雾——她跟着小羊走进一场**粉色的夜雾之梦**：灯笼街、羊群旋转木马、汽水海、会数羊的集市。雾最浓的时候，两只像极了爸爸妈妈的小黑羊出现（一只打着小红领带，一只围着白色外套布料做的小围巾），陪她走了一段路。梦里的旧汐斯塔火山亮起来，她穿上母亲的外套冲上山；在火山口的光里，两只羊有一瞬变回两个人的剪影，向她挥手，然后被雾温柔地收走。天亮了，她在博物馆的桌上醒来，汽水还在冒泡，标签上有一个粉色的小蹄印。
基调：梦幻、调皮又温柔的夜；粉 / 靛蓝 / 灯笼金；终段转成日出。

### III · 想你（Miss You）
开篇是地底：一滴滴岩浆（熔化的石头）从各处汇聚（呼应专辑介绍的意象），然后冲上地面——切到晴天下的城市：她拄着开花的法杖走在街上，白色灰烬像雪一样落。她在罗德岛录下身边人的声音、学会读唇语、给卡恩前辈和凯勒老师写信（信化作纸鸟飞走），然后出发去乌纳火山：重建后的乌纳村、夜里粉色小羊引路种下预警花（密录「夜色中的第一步」）、白天一步一步登上灰色的山坡（身后有父母当年的虚影同行）；半山腰差点晕倒、听不见助手的劝，继续走；山顶在云海之上，她埋下一块小石头，怀里的两个花环在无风的山顶自己飞了起来。最后的副歌是一场“喷发”——不是灾难，是光：满天的熔岩色极光、白灰与花瓣，灰落下的地方开出花。结尾她录下山顶的风，磁带标签写着「Miss You」。
基调：晴朗、辽阔、克制的思念，最后释放；白 / 天蓝 / 灰 / 一点红（外套系带、花瓣）/ 熔岩橙。

### 番外：汐斯塔的同一天（IV、V）
两支番外发生在**第二部那个夜晚之前的同一天**，一支跟着她，一支跟着小羊们；两支都停在夜里博物馆门口的**那只货箱**上。
- **货箱**：木板、`SIESTA` 字样的模板印、绳把手——设计以第二部 `misty-memory-night.js` 里的为准（第二部开场它在博物馆角落里一歪，滚出小羊和汽水瓶）。
- **时间线**：上午 船靠岸（IV）→ 下午 海边的汽水铺（V）→ 傍晚 码头与外套（IV）→ 夜里 灯笼与烟花、有人敲门（IV、V 各拍一面）→ 深夜 她在桌前睡着，第二部开始。
- 页面里的“那一天”时间线（`player.js` 的 `COPY.day`）就是这张表。

#### IV · 晴日之约（Misty Memory, Day）
凯勒老师邀她来汐斯塔帮忙打理火山博物馆、观测那座老火山。夏日的早晨，船靠岸：青绿的海、白房子、棕榈、海鸥。博物馆开馆日很热闹；粉色小羊一只接一只冒出来——只有她看得见，游客们只看见她对着空气说话，冰淇淋不翼而飞。像云一样的大粉羊多利现身，提出交易：**北风、种子、羊毛**，换她在找的东西。她跑遍了小镇（灯塔崖上的风车与风筝、凯勒老师花园里的预警花种子、羊毛店……每一样都差一点）。傍晚的码头上，她裹紧了母亲的外套，忽然明白：“羊毛”一直就在她身上（正史）。入夜，海湾上升起灯笼和烟花；她和凯勒老师在博物馆的露台上看。夜里有人轻轻敲门，门口只有一只嗡嗡冒泡的货箱；她笑着把它拖进来，回到桌前，打了个哈欠。
基调：晴朗、温暖、有点好笑，中段一次真诚的转折。**外套怎么来的不交代**（正史未写）。

#### V · 汽水（Effervescence）
汐斯塔最热的一个下午。一群谁也看不见的粉色小羊盯上了海边的汽水铺（老板是本页原创的路人，只看见瓶子自己飘起来、瓶盖一个接一个弹开）：叠成羊塔去够拉杆、灌装线失控、泡沫喷发、踩着泡沫冲浪、骑着汽水瓶飞过港口、屋顶上的汽水喷泉派对。闹够了，它们在灯笼亮起来的夜里拖着一只 `SIESTA` 货箱穿过小巷，到博物馆门口敲门，一头扎进箱子里；她开门、挑眉、笑着把箱子拖了进去。彩蛋：瓶盖上一个粉色的小蹄印。
基调：喜剧、明快、糖果色（青 / 薄荷 / 粉 / 柠檬黄），气泡满屏但保持可读。

## 3. 美术方向（三部共享）

- 画幅 16:9（1920×1080 设计坐标）；需要电影感时加 2.35:1 黑边（`s.post.letterbox`）。
- 全片统一的“绘本 × 动画电影”风格：平涂 + 柔和渐变 + 墨线（和本页 `js/scenes.js` 的插画同一路子），前后景分层做视差，空气感靠雾、光束、粒子。
- 胶片感：每部都加轻微颗粒（`s.post.grain`，0.03–0.06）与暗角；I 暖色、II 粉紫、III 冷白蓝。
- 字：旁白用 Noto Serif SC（`font: 'serif'`），标题用 Cinzel（`'display'`），I 的手写标签用 `'hand'`。旁白要少而准（每部 6–10 句），我们自己写。
- 剪辑：镜头长度多为 2 / 4 / 8 小节；大段落交界用转场（`in: { type, dur }`：fade / black / white / flash / slide / wipe / iris / zoom / tear / ash），段内多用硬切（cut）+ 镜头运动。重拍（`s.acc()`、`s.pulse()`、`s.lo`）驱动闪光、镜头微震、粒子爆发，但要克制。
- 片头：歌名 + 「MV · 本页原创」；片尾字幕：歌曲信息（按上表）+「影像：本页原创同人作品，与官方无关」+「角色与世界观 © Hypergryph」。

## 5. 技术要点（`js/mv/engine.js`）

- `MVE.film({...})` 注册影片；`shots` 是首尾相接的镜头（`t0` 开始，`t1` 默认到下一个镜头）。每个镜头 `draw(g, s)`：
  - `g` 已经变换到 1920×1080 的设计坐标。
  - `s.t` 绝对秒、`s.lt` 镜头内秒、`s.p` 镜头进度；`s.beat / s.bar / s.bp / s.barp`；`s.pulse()` 拍点脉冲、`s.barPulse()`；`s.e / s.lo / s.mid / s.hi` 平滑包络（0..1），`s.raw(key)` 原始包络，`s.acc(decay)` 重音脉冲。
  - `s.at(a,b,ease)` 镜头内时间段进度，`s.abs(a,b)` 绝对时间段进度，`s.window01(x,a,b,fi,fo)`。
  - `s.cache(key, (q)=>..., w, h)` 预渲染静态层（按分辨率自动重建）；**所有不动的大块背景都要缓存**。
  - `s.layer(g, cam, depth, fn)` 视差层；`s.handheld(seed, t, amp)` 手持漂移。
  - `s.field(g, t, spec)` / `s.kit.particles(g, t, 'snow'|'ash'|'embers'|'petals'|'fireflies'|'bubbles'|'dust'|'rain'|'sparkle', opts)`：粒子必须由 t 解析地算出来（纯函数），不要保存状态。
  - `s.kit.sky / stars / cloudSprite / fog / rays`，`s.post.vignette / grain / letterbox / fill / grade / leak`，`s.glow`，`s.text`。
- **纯函数原则**：`render(t)` 只依赖 t。不许在镜头里累加状态（这样才能任意跳转、离线测性能、实验页单帧渲染）。
- 影片可以有 `prepare(ctx)`（异步，`ctx.svg(str,w,h)` 把 SVG 栅格化成画布、`ctx.img(url)`）、`overlay(g, s)`（每帧最上层）、`captions: [[t0, t1, '文字', { style: 'narration'|'quote'|'hand'|'side', x, y, size }]]`。
- 结构数据：`MVE.analysis(url)`；影片里通过 `s.T`（`beatAt / barAt / beatTime / barTime / env / accent`）。

### 性能预算（1280×720，`lab/mv.html?film=<id>&perf=1`）
- 每帧 `render()` CPU：平均 ≤ 3ms，p95 ≤ 6ms；帧间隔 p95 ≤ 20ms（在无头 GPU 模式下）。
- 同屏柔光精灵 ≤ 400 个、粒子 ≤ 600 个；每帧新建的渐变对象越少越好（能缓存就缓存）。
- 转场期间会同时画两个镜头，转场里的两个镜头都要轻。

### 实验页工作流
- 单帧：`lab/mv.html?film=<id>&t=42.5&debug=1`
- 联系表：`lab/mv.html?film=<id>&strip=auto`（每个镜头的开头 + 中间）、`&strip=every:4`、`&strip=12,13.5`
- 性能：`lab/mv.html?film=<id>&perf=1`
- 截图：`pwsh lab/shot.ps1 -Page mv.html -Query "film=<id>&strip=auto&cols=6&cw=320" -Out <png> -Width 2000 -Height 1400 -Base http://localhost:25568`
  （或 `node lab/cdp.mjs`）。用 Read 看截图，像苛刻的动画导演一样挑毛病，反复改。

## 6. 分工与文件归属
